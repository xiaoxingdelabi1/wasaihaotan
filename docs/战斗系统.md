# 战斗系统文档

## 一、角色属性

### 基础属性
| 属性 | 初始值 | 作用 |
|------|--------|------|
| strength (力量) | 10 | 影响攻击力 |
| agility (敏捷) | 8 | 影响暴击率和闪避 |
| intelligence (智力) | 5 | 影响技能效果 |
| vitality (体质) | 12 | 影响生命值和防御 |

### 战斗属性
| 属性 | 初始值 | 计算公式 | 上限 |
|------|--------|----------|------|
| attack (攻击力) | 20 | `10 + strength * 2 + 装备加成 + 套装加成` | 无 |
| defense (防御力) | 5 | `5 + vitality * 0.5 + 装备加成 + 套装加成` | 无 |
| maxHealth (最大生命) | 100 | `80 + vitality * 10 + 装备加成 + 套装加成` | 无 |
| criticalChance (暴击率) | 5% | `5 + agility * 0.5 + 装备加成 + 套装加成` | 50% |
| criticalDamage (暴击伤害) | 150% | 固定值 + 套装加成 | 无 |
| monsterDamage (对怪伤害加成) | 0% | 装备加成 + 套装加成 | 无 |
| dodge (闪避率) | 3% | `3 + agility * 0.3 + 装备加成 + 套装加成` | 30% |

### 升级属性成长
每次升级获得：
- strength +2
- agility +1
- intelligence +1
- vitality +2

## 二、伤害计算公式

### 玩家攻击伤害

```
基础伤害 = Character.attack

怪物伤害加成后伤害 = 基础伤害 * (1 + Character.monsterDamage / 100)

暴击伤害 = 加成后伤害 * (Character.criticalDamage / 100)

最终伤害 = 暴击判定 ? 暴击伤害 : 加成后伤害
```

**示例计算：**
- 假设 attack = 100，monsterDamage = 20%，criticalDamage = 150%
- 加成后伤害 = 100 * (1 + 20/100) = 120
- 暴击伤害 = 120 * 150/100 = 180

### 怪物攻击伤害

```
基础伤害 = monster.attack - Character.defense

最终伤害 = Math.max(1, 基础伤害)
```

**注意：** 怪物攻击伤害最低为 1，防御力不能完全抵消伤害。

## 三、战斗流程

### 冒险模式自动战斗 (adventure.js)

```
战斗循环 (每 500ms 一回合)
    │
    ├── 检查玩家是否死亡 → 是 → onPlayerDeath()
    │
    ├── 玩家攻击
    │   ├── 计算基础伤害 = Character.attack
    │   ├── 应用怪物伤害加成
    │   ├── 暴击判定 (random < criticalChance)
    │   └── 扣除怪物血量
    │
    ├── 检查怪物是否死亡 → 是 → monsterDefeated()
    │
    ├── 怪物反击
    │   ├── 闪避判定 (random < dodge) → 闪避成功
    │   ├── 计算伤害 = max(1, monster.attack - defense)
    │   └── 扣除玩家血量
    │
    └── 检查玩家是否死亡 → 是 → onPlayerDeath()
```

### 手动战斗模式 (combat.js)

```
战斗循环 (每 1000ms 一回合)
    │
    ├── 玩家回合
    │   ├── 技能冷却递减
    │   ├── 优先使用技能 (powerStrike 可用时)
    │   │   └── 强力攻击: damage = attack * 1.5
    │   └── 否则普通攻击
    │
    ├── 检查怪物是否死亡 → 是 → endCombat(true)
    │
    ├── 怪物回合
    │   ├── 闪避判定
    │   ├── 计算伤害
    │   ├── Boss技能判定 (魔王每3回合伤害*1.5)
    │   └── 扣除玩家血量
    │
    └── 检查玩家是否死亡 → 是 → endCombat(false)
```

## 四、特殊机制

### 暴击系统
```javascript
if (Math.random() * 100 < Character.criticalChance) {
    damage = Math.floor(damage * (Character.criticalDamage / 100));
}
```
- 暴击率上限：50%
- 默认暴击伤害：150%

### 闪避系统
```javascript
if (Math.random() * 100 < Character.dodge) {
    // 闪避成功，不受到伤害
}
```
- 闪避率上限：30%

### 对怪物伤害加成
```javascript
damage = Math.floor(damage * (1 + Character.monsterDamage / 100));
```
- 通过装备获得该属性
- 直接乘算增加最终伤害

## 五、怪物类型

### 普通怪物
- 基础属性来自怪物配置

### 精英怪物 (城堡地区)
```javascript
// 30% 概率生成精英 (冒险模式)
// 40% 概率生成精英 (手动战斗)
if (Math.random() < 0.3) {
    monster.name = `精英 ${monster.name}`;
    monster.health *= 1.5;
    monster.attack *= 1.5;
    monster.defense *= 1.5;
    monster.experience *= 2;
}
```

### BOSS 怪物
```javascript
// 每10只怪物后生成BOSS
boss.name = `BOSS - ${boss.name}`;
boss.health = baseHealth * 3;
boss.attack = baseAttack * 2;
boss.defense = baseDefense * 2;
boss.experience = baseExp * 5;
boss.gold = baseGold * 5;
```

### 魔王特殊技能
```javascript
// 每3回合释放毁灭之击
if (combatTurnCount % 3 === 0) {
    damage = Math.floor(damage * 1.5);
}
```

## 六、死亡处理

### 冒险模式死亡
1. 返回上一地区（如果是第一地区则留在原地）
2. 重置击杀计数器
3. 自动满血复活
4. 1秒后继续战斗

### 手动战斗死亡
1. 损失 10% 金币
2. 战斗结束
3. 需要手动恢复血量

## 九、伤害计算示例

### 示例1：普通攻击
```
玩家属性: attack=100, monsterDamage=20%, criticalChance=10%, criticalDamage=150%
怪物属性: defense=20

伤害计算:
1. 基础伤害 = 100
2. 怪物伤害加成 = 100 * 1.2 = 120
3. 暴击判定: random(0-100) < 10 → 未暴击
4. 最终伤害 = 120
```

### 示例2：暴击攻击
```
玩家属性: attack=100, monsterDamage=20%, criticalChance=10%, criticalDamage=150%

伤害计算:
1. 基础伤害 = 100
2. 怪物伤害加成 = 100 * 1.2 = 120
3. 暴击判定: random(0-100) < 10 → 暴击！
4. 暴击伤害 = 120 * 1.5 = 180
5. 最终伤害 = 180
```

### 示例3：怪物攻击玩家
```
怪物属性: attack=50
玩家属性: defense=30, dodge=15%

伤害计算:
1. 闪避判定: random(0-100) < 15 → 未闪避
2. 基础伤害 = 50 - 30 = 20
3. 最终伤害 = max(1, 20) = 20
```

### 示例4：高防御情况
```
怪物属性: attack=30
玩家属性: defense=50

伤害计算:
1. 基础伤害 = 30 - 50 = -20
2. 最终伤害 = max(1, -20) = 1
```
